# Known vulnerable drivers used by BYOVD attacks.
#
# One file name per line, lowercase. '#' starts a comment.
#
# This is a starting point, not a threat feed. It covers drivers that appear
# repeatedly in public BYOVD reporting; it is not exhaustive and it will age.
# Update it from the Microsoft vulnerable driver blocklist or LOLDrivers
# (https://github.com/magicsword-io/LOLDrivers), or pass your own file with
# --names.
#
# Matching is by file name on purpose: a name is what a loader keeps when it
# reuses a signed driver, while hashes change with every build.
